# Lumora

**Social media that gives time back.**

Lumora is a concept social network that keeps the good parts of the feeds people
already use — and drops the parts built to trap them. Learn something, laugh once,
connect for real, then it tells you you're done.

*Lu·mo·ra* — from Latin *lumen* (light) + *aura*: the glow of time well spent.

## The idea

Every big platform got one thing right and one thing wrong. Lumora keeps the first
and refuses the second:

| Platform  | Keep | Drop |
|-----------|------|------|
| LinkedIn  | Real expertise, showing up as yourself | Humble-brag theatre, cold-DM spam |
| Twitter/X | A clean thought traveling on merit | Dunk culture, outrage ranking, the bottomless scroll |
| Telegram  | Fast, private, well-run rooms | Unmoderated chaos, 5,000-person firehose |
| Facebook  | Finding your people, events, local life | Ad-stuffed feeds, engagement bait |
| Instagram | The joy of sharing what you made or saw | Like-count anxiety, the filter arms race |

## Four rules the product can't quietly break

1. **Finite by default** — every feed has a bottom; it tells you when you've seen the day's best.
2. **No vanity scoreboard** — no public like counts or follower flex; reactions are private "this helped me" signals.
3. **Ranked by worth, shown in order** — posts stay chronological; quality surfaces, nothing is secretly reordered to provoke.
4. **You are not the product** — membership-funded, no surveillance ads, so no reason to trap you.

## Running it

It's a single static page. Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000   # then visit http://localhost:8000
```
